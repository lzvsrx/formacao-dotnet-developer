# Guia Azure
1. Crie um Azure App Service com runtime .NET compatível.
2. Configure ASPNETCORE_ENVIRONMENT e segredos em Application Settings.
3. Faça deploy da API da pasta 05-APIs via `dotnet publish -c Release`.
4. Habilite logs, HTTPS e monitoramento.
Nenhum recurso em nuvem é criado automaticamente.
