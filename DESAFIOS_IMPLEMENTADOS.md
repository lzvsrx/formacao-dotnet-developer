# Desafios implementados

Os seis desafios em `08-Desafios-Praticos` são implementações didáticas independentes, inspiradas em temas comuns da formação; **não foram verificados contra os enunciados autenticados de cada aula da DIO**.

| Desafio | Conceitos |
|---|---|
| DesafioEstacionamento | C# / .NET 10 |
| DesafioHospedagem | C# / .NET 10 |
| DesafioContaBancaria | C# / .NET 10 |
| DesafioSmartphone | C# / .NET 10 |
| DesafioCalculadoraTestavel | C# / .NET 10 |
| DesafioCatalogoJogos | C# / .NET 10 |

Executar: `dotnet run --project 08-Desafios-Praticos/DesafioHospedagem` (substitua o nome).

**Validação:** o SDK dotnet não está instalado neste ambiente; não foi possível compilar ou executar os projetos aqui.
